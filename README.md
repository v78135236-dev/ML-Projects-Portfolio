# Machine Learning Projects Portfolio

A collection of five machine learning and NLP projects focused on text classification, content moderation, and applied deep learning.

**Author:** Chaitanya  
**GitHub:** [v78135236-dev](https://github.com/v78135236-dev)

## Projects

### 1. BERT Toxic Content Moderation
A transformer-based NLP project for identifying toxic and harmful online comments.

- **Tech:** Python, PyTorch, Hugging Face Transformers, BERT
- **Model:** Fine-tuned BERT for toxic content classification
- **Folder:** `BERT-Toxic-Content-Moderation/`

### 2. Hate Speech Detection
An NLP classification project for detecting hate speech in text.

- **Tech:** Python, BERT, PyTorch, Hugging Face Transformers
- **Folder:** `Hate-Speech-Detection/`

### 3. Sensitive Content Detection
A transformer-based text classification project for identifying sensitive content.

- **Tech:** Python, NLP, BERT, PyTorch
- **Folder:** `Sensitive-Content-Detection/`

### 4. Spam Detection
A text classification project for identifying spam messages.

- **Tech:** Python, NLP, BERT, PyTorch
- **Folder:** `Spam-Detection/`

### 5. Violence Detection
An NLP classification project for identifying text associated with violent content.

- **Tech:** Python, NLP, BERT, PyTorch
- **Folder:** `Violence-Detection/`

## Getting Started

1. Clone this repository.
2. Open the folder for the project you want to explore.
3. Follow that project's README for setup instructions and dependencies.
4. Download or configure the required model files if they are not included.

## Model Storage

Large `.safetensors` model files are tracked using **Git LFS**. Git LFS must be installed to download the actual model weights.

Install Git LFS: https://git-lfs.com/

## Purpose

This portfolio brings together practical machine learning and NLP projects in one repository for easier exploration and review.
